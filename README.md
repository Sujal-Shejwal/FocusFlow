# FocusFlow

A modern Pomodoro productivity app with a clean cyberpunk-inspired UI to help you stay focused and manage tasks efficiently.

## Features

* Pomodoro Timer
* Short & Long Break Modes
* Daily Task Management
* Ambient Music Support
* Responsive UI
* Local Storage Support

## Tech Stack

* React.js
* JavaScript
* CSS
* Vercel

## Live Demo

## Run Locally

```bash
git clone https://github.com/Sujal-Shejwal/FocusFlow.git
cd FocusFlow
npm install
npm start
```
